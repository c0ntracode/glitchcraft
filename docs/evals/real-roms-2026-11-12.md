# Real ROMs and published codes (2026-11-12)

The author supplied dumps of games he owns (git-ignored `roms/`). Published Game Genie codes were gathered by search, then decoded and vetted against the real files. A 9-digit (or NES 8-letter) code carries a compare byte: when it equals the ROM byte at the patched address, in the bank the code was written for, that is independent evidence the codec and the address-to-file mapping are right. Effects below are published claims, not checked in a game. The tests that keep this evidence alive are in `tests/test_real_roms.py` (they skip when a ROM is absent).

| Console | ROM | Result |
|---|---|---|
| Game Gear (Sega mapper) | Sonic Chaos | `3A6-24E-2A2` ("infinite lives") matches at `$1624`: `LD ($D29B),A` becomes `LD A,($D29B)`, so the decremented lives are never stored. `008-3BD-E6E` ("stop timer") matches at `$283B`: `ADD A,1` becomes `ADD A,0` before `DAA`. |
| Game Gear (Sega mapper) | Sonic the Hedgehog V1.0 and V1.1 (and a prototype) | 7 of the 8 published Sonic 1 Game Gear codes matched the revision they were written for and no other (v1 codes only in V1.0, v2 codes only in V1.1; banked ones in one bank each). The eighth, `020-54A-E6E` ("rings worth 2"), is the V1.0 code in bank 1; its extra compare matches in bank 6 (both revisions) are coincidences, shown by the in-game check (`ingame-sonic-gg-rings.md`: bank 6 on V1.1 has no effect; the routine moved in V1.1). A bank scan can produce chance matches, about 1 in 256 per bank scanned, so a match is evidence only together with the expected bank and an instruction that fits the stated effect. Instructions fit the stated effects (`DEC (HL)`->`NOP` for lives; `LD ($D296),HL`->`LD HL,($D296)` for air; `LD A,3`->`LD A,1` for start lives; `LD (HL),A`->`NOP` for the timer). None applied to the prototype, the Master System build or Sonic Chaos. The prototype's header says Master System even though the file is `.gg`. |
| Master System | Sonic the Hedgehog (UE) | No published code matched: they are Game Gear codes (and the Master System ones are Pro Action Replay RAM codes). The Z80 disassembler swept all 16 banks cleanly. |
| Game Boy MBC1 | Link's Awakening Rev 2 | All 11 published codes tried matched, in the right banks (bank 2 and 3 for banked ones; bank 0 for the rest). |
| Game Boy MBC3 | Pokémon Red | All matched in the stated banks (1, 3, 15, 26, and bank 0); one code with compare `$00` matched 25 banks and is ambiguous by nature. |
| Game Boy, no mapper | Tetris V1.1 | All matched; two codes also produced the same frame in Gambatte as `patch-copy`. |
| NES MMC1 | Mega Man 2 | 9 of 9 compare bytes matched, 4 in fixed bank, 5 in exactly one switchable bank each. |
| NES MMC3 | Super Mario Bros. 3 (Rev 1) | 5 of 8 matched in exactly one bank each; the three misses are in the fixed area and are probably PRG0 codes. `vet` caught one as turning a `JSR` into a `KIL`. |
| SNES HiROM | EarthBound | 9 codes plausible by eye (no compare byte); `C2:`, `42:` mirrors agree; low-half addresses refuse correctly. |
| Genesis | Sonic 1 REV00 (clean) | 4 of 5 public codes land on the intended instructions (infinite lives skips the `SUBQ`, start lives edit the `MOVE.B #3`, level select flips a `BEQ` to `BRA`); `JXGA-CA7G` lands in data. |
| Master System (Codemasters) | Micro Machines (E) | The Codemasters header heuristic matched a real dump (bank count and checksum plus complement); the game writes bank numbers to `$8000`. The mapper is now mapped instead of refused. No published code was available to test. |
| Genesis | Micro Machines (no `SEGA` header) | Found by this run: now identified from its vector table with a warning. |

## Defects this run found (all fixed, tests added)

- A Genesis ROM with code instead of the `SEGA` header at `$100` (unlicensed games) was "not recognized".
- `xrefs` missed indexed operands on NES and SNES (`LDA $4016,X` was not found when asking for `$4016`).
- `disasm` of a RAM address suggested `--bank`; `xrefs` silently accepted `--bank`.
- `decode` gave no warning for a compare byte that does not match the ROM; `patch-copy` gave no bank hint.

## Not covered

No effect was run in a game. Banked codes were not run through an emulator on these real ROMs. Several lists come from a single site. The Sonic Chaos `[b1]` bad dump and the Japanese Sonic & Tails dump were identified (`id`) but not examined further. The codes' stated revisions were not verified against a database.
